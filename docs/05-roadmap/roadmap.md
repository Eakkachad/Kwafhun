## แผนรายเฟส / Phased Roadmap

### Phase 1 — Pilot: City-First (6–12 เดือน)
> เริ่มจากเมืองหัวเมืองที่มีทรัพยากรแล้ว ไม่เริ่มจากชนบท — KPI หลัก + วิธีวัด ดูใน `docs/03-architecture/PRD.md` §6
- **ขอบเขต:** มหาวิทยาลัยเครือข่าย 4 แห่ง (บูรพา/นเรศวร/มข/มช) + โรงเรียนหัวเมืองใกล้เคียง
- **ตัวชี้วัด (วัดผลได้จริง — เครื่องมือ + baseline ระบุใน PRD §6):**
  - North Star: % นักเรียน "ตัดสินใจได้" (pre-post 5 ข้อ) — baseline จาก 30 คนแรก
  - Engagement: % เรียนคอร์สจบ ≥1 (เป้า > 60% ของที่เริ่ม)
  - Screening yield: % ผ่าน screening → เข้าค่ายจริง (เป้า > 30%)
  - Teacher time: < 5 นาที/คาบ ในการได้รายงาน (ระบบจับเวลา)
  - Teacher reuse: > 50% ใช้ซ้ำเดือนถัดไป
  - Pipeline: แมตช์ทุนจริง ≥ 10 คนใน pilot
- **Demo เป้าหมายสำหรับ Hackathon:** Discovery + คอร์ส Learn + Achievement + Roadmap + Teacher PDF (4 หน้าจอฉลุย)

### Phase 2 — Mid-term Expansion (1–3 ปี)
- **ขอบเขต:** ขยายผ่านเครือข่าย สพฐ. 7,000+ แห่ง + AIS Academy Network
- **ตัวชี้วัด (ใน pilot ต้องพิสูจน์ก่อน):**
  - % นักเรียนที่เปลี่ยน/ยืนยันความตั้งใจสายอาชีพหลังใช้ (วัด pre-post ใน pilot)
  - แมตช์ทุน กสศ./มหาวิทยาลัย > 15,000 คน (สะสม)
  - อัตราการคงอยู่ในระบบของกลุ่ม pilot สูงกว่ากลุ่มเปรียบเทียบ (ระบุเป็น "วัดผล pilot" ไม่ใช่การเคลมระดับชาติ)

> ⚠️ **ห้ามเคลม:** ตัวเลข "Q1 เรียนต่อ +15–20%" และ "ลด dropout 30%" เป็นผลมหภาคที่**ยังไม่มีหลักฐาน causal** (research เองยอมรับว่ายังไม่มี RCT ในไทย) — นำเสนอได้ในฐานะ "ทิศทาง/สมมติฐานที่เราจะวัดใน pilot" เท่านั้น

### Phase 3 — Macro Impact (3–5 ปี)
- **เป้า (ระยะยาว, ต้องมีหลักฐานจาก pilot ค่อยๆ scale):** สนับสนุนการผลิตกำลังคนทักษะสูงในสาย STEM/AI/Digital
- **เป้า:** บรรเทาความสูญเสียจาก Skill Mismatch — **ห้ามอ้างว่าเราลด 3.3 ล้านล้านได้** ให้เล่าเป็น "บริบทของปัญหาที่เรามุ่งแก้" ไม่ใช่ "ผลลัพธ์ที่เราวัดได้"

| "ลดภาระงาน 70%" | ❌ ยกเลิก — เปลี่ยนเป็น "ออกแบบให้งานเอกสารต่อคาบอัตโนมัติ" | ทุกบริบท |
