# Design — แฟ้มงานออกแบบ

> สำหรับ UX/UI Designer — เก็บ wireframe, mockup, โลโก้, สไลด์

## โฟลเดอร์

| โฟลเดอร์ | ใช้เก็บ | สถานะ |
|---|---|---|
| `slides/` | ไฟล์สไลด์ (PPTX / PDF / Figma export) | ว่าง — รอจาก pitch-deck.md |
| `logo/` | โลโก้ / แบรนด์ "คว้าฝัน" | ว่าง |
| `wireframes/` | Mockup หน้าจอ PWA (Discovery / Roadmap / Teacher Dashboard) | ว่าง |

## แนวคิดแบรนด์ (Brand Direction)

- **โทนสี:** สีสดใสวัยรุ่น (ไม่ได้กำหนดตายตัว — เสนอได้)
- **ลุค:** สนุก ฝันถึงอนาคต แต่ไม่ขายฝัน (อ้างอิงสไตล์ Roadtrip Nation — จริงใจ ผ่านเรื่องจริง)
- **ไฟล์ดิบ/ใหญ่** (ภาพต้นฉบับ PSD/AI) อย่า commit ลง repo ให้เก็บไว้ข้างนอกแล้ว commit เฉพาะไฟล์ export

## ขั้นตอนเริ่มงาน

1. ดู `docs/01-pitch/pitch-deck.md` เพื่อดึงหน้าจอที่ต้องออกแบบ (Slide 5: Discovery, Dream Roadmap, Teacher Dashboard)
2. ออกแบบ wireframe โทนขาวดำก่อน → อนุมัติ → ต่อยอดเป็น high-fidelity
3. นำไฟล์ export มาวางในโฟลเดอร์ที่ตรง แล้วเปิด PR
