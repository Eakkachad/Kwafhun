## 2. ที่มาและความสำคัญของปัญหา (Background & Problem Insight)

> ประเทศไทยกำลังเผชิญกับวิกฤต "ความเหลื่อมล้ำทางการศึกษาและกับดักความยากจนข้ามรุ่น" เด็กและเยาวชนในพื้นที่ห่างไกลเผชิญกับ ภาวะขาดแคลนต้นแบบในชีวิตจริง (Role Model Deficit) สภาพแวดล้อมจำกัดโอกาสในการมองเห็นอาชีพที่หลากหลาย นำไปสู่ปัญหา "ข้อจำกัดในการตั้งความฝัน" (Dream Gap) ตามทฤษฎีการตัดตัวเลือกอาชีพในวัยเด็ก (Theory of Circumscription & Compromise - Gottfredson) เด็กจะเริ่มตัดอาชีพทักษะสูงออกจากตัวเลือกในชีวิตตั้งแต่อายุเพียง 6–8 ปี เนื่องจากมองไม่เห็นความเป็นไปได้รอบตัว

**ข้อมูลเชิงประจักษ์สะท้อนวิกฤตความเหลื่อมล้ำ:**

- **ช่องว่างโอกาสในการเรียนต่ออุดมศึกษา:** ประเทศไทยมีนักเรียนยากจนและยากจนพิเศษกว่า 1.8 ล้านคน (มีรายได้เฉลี่ยเพียง 34–41 บาท/วัน) โดยเด็กจากครัวเรือนยากจนที่สุด 20% ของประเทศ มีโอกาสเข้าศึกษาต่อระดับอุดมศึกษาเพียง 10–12.4% ขณะที่กลุ่มฐานะดีที่สุดมีโอกาสสูงถึง 65–80% หรือแตกต่างกันกว่า 5–6 เท่า *(ที่มา: รายงานสถานการณ์ความเหลื่อมล้ำทางการศึกษา กสศ.)*
- **ภาวะฝันกระจุกตัว (Career Narrowing):** เด็กเยาวชนอายุ 15 ปี มากกว่า 47–50% มุ่งหวังประกอบอาชีพกระจุกตัวอยู่เพียง 10 อาชีพดั้งเดิม (เช่น หมอ ครู ตำรวจ ทหาร) เนื่องจากขาดการรับรู้ถึงอาชีพแห่งอนาคต *(ที่มา: OECD PISA Career Expectations Study)*
- **วิกฤตขาดแคลนแรงงานทักษะสูง:** ประเทศไทยกำลังขาดแคลนแรงงานทักษะสูง (STEM, AI, Digital) มากกว่า 300,000–500,000 คน และปัญหาทักษะไม่ตรงสายงาน (Skill Mismatch) สร้างความสูญเสียทางเศรษฐกิจสูงถึง 3.3 ล้านล้านบาท *(ที่มา: สภาพัฒน์ NESDC และ TDRI)*

**ข้อจำกัดของระบบการศึกษาในปัจจุบัน:**
โรงเรียนขยายโอกาสในต่างจังหวัดกว่า 7,000 แห่ง ขาดแคลนระบบการแนะแนวที่มีประสิทธิภาพ สื่อการสอนยังเป็นแบบทดสอบกระดาษเดิมๆ ไม่ทันกับอาชีพยุคใหม่ และครูประจำชั้นต้องแบกรับภาระงานเอกสารนอกห้องเรียนสูง ทำให้ขาดเครื่องมือช่วยจัดกิจกรรมแนะแนวที่เห็นผลจริง

นวัตกรรม **"คว้าฝัน" (Catch the Dream)** จึงถูกคิดค้นขึ้นเพื่อแก้ปัญหาที่ต้นตอของแรงจูงใจ (Intrinsic Motivation) โดยเปลี่ยนหน้าต่างการแนะแนวให้เป็น The Netflix of Dreams ร่วมกับ AI Personalized Action Plan เพื่อย่อยเป้าหมายใหญ่เป็นขั้นตอนที่ทำได้จริง และเป็น Opportunity Router ที่เชื่อมต่อเด็กยากจนเข้าหาทุนการศึกษา (กสศ.) และหลักสูตรพัฒนาทักษะดิจิทัล (AIS LearnDi) เพื่อเปลี่ยนความฝันให้เป็นความจริงอย่างยั่งยืน

**จุดเด่นของร่างคำตอบ:**
- ระบุปัญหาครบ 3 ระดับ: บุคคล (Dream Gap) / ระบบการศึกษา (ภาระครู) / เศรษฐกิจมหภาค (Skill Mismatch)
- อ้างอิงแหล่งน่าเชื่อถือ: กสศ., NESDC, TDRI, OECD PISA
- ตรงเกณฑ์ Problem-Solution Fit (35%)

## 3. กลุ่มเป้าหมาย (Target)

### 3.1 กลุ่มเป้าหมายหลัก (Primary Target Users)

- **ประชากรศาสตร์ (Demographics):** นักเรียนระดับ ป.5 – ม.3 เพศชาย/หญิง อายุ 10–15 ปี
- **ภูมิศาสตร์ (Geography):** เริ่มจากนักเรียนในเมืองหัวเมือง/จังหวัดใหญ่ (ชลบุรี, พิษณุโลก, ขอนแก่น, เชียงใหม่) ที่มีมหาวิทยาลัยเครือข่ายรองรับ แล้วค่อยขยายสู่พื้นที่ห่างไกล — กลุ่มที่ยัง "ไม่รู้ว่าจะไปทางไหน" ในโรงเรียนเมืองก็มีจำนวนมากเช่นกัน
- **จิตวิทยา (Psychographics):** ยังไม่รู้ความถนัด/ทิศทางอาชีพ อยากได้ประสบการณ์ "ลองทำจริง" เพื่อตัดตัวเลือก (ได้รู้ → ได้ลอง → ได้ทำจริง) มีความอยากรู้อยากเห็นแต่ขาดแรงจูงใจระยะยาว
- **พฤติกรรม & ไลฟ์สไตล์ (Behaviors):** คุ้นเคยวิดีโอสั้นและแพลตฟอร์มเรียนออนไลน์ (Netflix/Coursera) มีข้อจำกัดด้านอุปกรณ์ส่วนตัวและเน็ตความเร็วสูงที่บ้าน → ระบบออกแบบให้ **การเรียนคอร์สและการคัดกรองเกิดในคาบเรียน** (ผ่านหน้าจอห้องเรียน/ครู) เพื่อไม่ให้เด็กที่มีทรัพยากรน้อยเสียเปรียบ
- **จำนวนเป้าหมายหลัก (Target Volume):** ประมาณ 3,200,000 คน (นักเรียน ป.5 – ม.3 ทั่วประเทศ) — เริ่มจากเมืองนำร่องก่อน

### 3.2 กลุ่มเป้าหมายร่วม / ผู้เอื้ออำนวย (Secondary Target / Facilitators)

- **ครูผู้สอน/ครูประจำชั้น/ครูแนะแนว:** ในโรงเรียนกว่า 7,000 แห่ง ประมาณ 150,000 คน ต้องการสื่อแนะแนวสมัยใหม่ + เครื่องมือลดงานเอกสาร
- **มหาวิทยาลัยเครือข่าย:** ม.บูรพา, ม.นเรศวร, ม.ขอนแก่น, ม.เชียงใหม่ — ค่าย Open House, สถานที่, นิสิตพี่เลี้ยง (Mentor)
- **พันธมิตรเครือข่าย:** ผู้ปกครอง, กสศ., สพฐ., AIS Academy (LearnDi), ผู้สนับสนุนค่าที่นั่ง Bootcamp

## 4. แนวคิดของไอเดียที่นำเสนอ (Solution Concept)

> รายละเอียดเชิงลึก (positioning, user journey, MVP scope, KPI, business model) ดู `docs/03-architecture/PRD.md` — เอกสารนี้คือฉบับสรุปสำหรับกรอกใบสมัคร

> "คว้าฝัน" คือ **"Netflix of Jobs"** — แพลตฟอร์มค้นหาอาชีพเชิงโต้ตอบที่ขับเคลื่อนด้วย **Knowledge Graph + Constraint-Aware Matching Engine** แทนที่จะเป็นเพียงคลังวิดีโอหรือแบบทดสอบบุคลิกภาพแบบเดิม โดยแก้ปัญหาที่ระบุไว้ในข้อ 2 ทีละมิติดังนี้:

| ปัญหา (จากข้อ 2) | กลไกที่ "คว้าฝัน" ใช้แก้ |
|---|---|
| Dream Gap / ฝันกระจุก 10 อาชีพ (47–50%) | **Job Recommendation บน Knowledge Graph**: ทุกครั้งที่เด็กดู/สนใจอาชีพหนึ่ง ระบบแนะนำอาชีพที่ "เชื่อมกันด้วยทักษะ" ที่เด็กอาจไม่เคยเห็น (เช่น สนใจ Data Scientist → เห็น ML Engineer, Bioinformatician, Actuary) เปิดขอบเขตความฝันอย่างเป็นระบบ ไม่ใช่สุ่ม |
| ขาด Role Model / มองไม่เห็นอาชีพจริง | คอนเทนต์หลัก **"A Day With..."** — วิดีโอสั้น "1 วันกับอาชีพจริง" (1 วันกับ Data Scientist / 1 วันกับวิศวกรอวกาศ ฯลฯ) จาก Crowdsourced Role Model Network |
| การแนะแนวแบบเดิมไม่ได้ผลเป็น Action Plan จริง | **Constraint-Aware Matching Engine** ตัดตัวเลือกที่ "เป็นไปไม่ได้" ออกก่อน (veto) แล้วจัดลำดับที่เหลือ (rank) เดินบน Knowledge Graph จากโปรไฟล์ความสนใจเด็ก ประกอบเป็น "1-Page Dream Roadmap" ที่จบที่องค์กรจริง (คอร์ส/ทุน/มหาวิทยาลัย) ไม่ใช่คำแนะนำลอยๆ |
| เด็กยากจนเข้าไม่ถึงทุน/โอกาสที่มีอยู่แล้ว | **Opportunity Router**: Roadmap เดียวกันเชื่อมตรงไปยังทุน กสศ. / มหาวิทยาลัยเครือข่าย / AIS LearnDi ที่ตรงกับเส้นทางของเด็กคนนั้น |

**กลไกทางเทคนิค (Technical Mechanism):**

1. **Knowledge Graph** เป็นแกนกลางเดียวที่ขับเคลื่อนทั้ง Discovery, Learn และ Plan/Connect — Node: `Job`, `Skill`, `Pathway/Course`, `Organization` (มหาวิทยาลัย/กสศ./นายจ้างพันธมิตร/AIS LearnDi), `Content`; Edge: `requires_skill`, `leads_to`, `offered_by`, `sponsors`, `related_to`
2. **Constraint-Aware Matching Engine ("veto, not vote")** — ตัดตัวเลือกที่เข้าเงื่อนไขไม่ได้ออกก่อน (hard constraint: ระดับชั้น/เกณฑ์ทุน/พื้นที่/วิชาพื้นฐาน) แล้วจัดลำดับที่เหลือ (soft) ใช้หลักเดียวกันทั้งแนะนำอาชีพและแมตช์ทุน — **deterministic, instant-update (ไม่ต้อง retrain), ทุกคำแนะนำ trace กลับที่มาข้อมูลได้** (ไม่ใช่ LLM/RAG แบบ black-box — ดู `docs/03-architecture/risk-defense.md`)
3. ระบบคัดกรองความสนใจ (Screening) เกิดขึ้น**ในคาบเรียน** ทุกคนเรียนเท่ากัน ป้องกันไม่ให้ "Netflix of Jobs" กลายเป็นสิทธิพิเศษของเด็กมีทรัพยากรที่บ้าน (ดู `docs/03-architecture/risk-defense.md` — Overclaim 6)

**การบูรณาการเทคโนโลยี AIS ในโซลูชัน:**
- **AIS Cloud** โฮสต์ Knowledge Graph DB + Constraint-Aware Engine ระดับ Enterprise — engine เบาพอประมวลผลที่ Edge/Local ได้จริง
- **AIS LearnDi** เป็นทั้งแหล่งคอร์ส/Digital Badge ในกราฟ และปลายทางหนึ่งของ Roadmap (เส้นทางสะสม Badge สู่ Portfolio)
- **AIS 5G/Fibre + PLAYBOX** ส่งคอนเทนต์ "A Day With..." แบบ Offline-Ready ถึงห้องเรียนที่เน็ตไม่เสถียร

**จุดเด่นของร่างคำตอบ:**
- ตอบโจทย์ Problem-Solution Fit ครบ — ทุกกลไกผูกกับปัญหาที่ระบุไว้ในข้อ 2 แบบ 1:1 ไม่ใช่ฟีเจอร์ลอยๆ
- แสดงความสามารถเชิงเทคนิคจริงที่ทำได้ใน 3 วัน (Knowledge Graph + Constraint-Aware Engine, deterministic) ตรงเกณฑ์ Technical Capabilities (35%) โดยไม่ต้องพึ่งการเทรน/เรียก LLM ที่เสี่ยงพังหน้า demo
- ควบคุม Overclaim: ไม่เคลมว่าใช้ "AI agent" หรือ RAG — ระบุเป็น Constraint-Based Engine ที่ deterministic และ trace ได้เสมอ; "ข้อมูลพันธมิตรองค์กร/นายจ้าง" ระบุเป็น**เป้าหมายการเป็นพันธมิตร** ไม่ใช่การอ้างสิทธิ์เข้าถึงข้อมูลที่มีอยู่แล้ว (ดู `docs/03-architecture/risk-defense.md`, `docs/04-research/deepman-integration.md`)
